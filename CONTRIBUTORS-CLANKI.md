Clanki is a fork of Anki, developed in the open at
https://github.com/Expertium/Clanki.

This file is about one thing: letting Anki reuse code that was written for
Clanki. Anki accepts contributions only under the BSD 3 clause license (see
`CONTRIBUTORS`), so code that is available only under the AGPL cannot go back
to Anki, AnkiWeb, AnkiMobile or AnkiDroid.

A permission like that can be given only by the person who holds the
copyright to the code. It cannot be granted on someone else's behalf, and
this file does not claim otherwise. So the permission below covers **only the
code whose author has granted it**, one author at a time, and only that
author's own work:

- Code in Clanki that came from Anki is Anki's, under Anki's own licenses
  (`LICENSE`). Nothing here changes that.
- Code in Clanki written by another author keeps that author's terms until
  that author says otherwise. See "Not covered" below.
- For your own contribution, you decide. Add your name below, or say so in
  your pull request, and Anki may reuse that contribution under BSD 3
  clause. Leave it out and it stays AGPL-only, which is a perfectly normal
  answer.

You keep the copyright to your work either way. The permission is
additional, not a replacement: Clanki itself stays AGPL-3 (`LICENSE`), and
nothing changes for anyone who only uses Clanki.

A name is not required. A pull request that states the same thing is enough.
If a pull request contains code you do not own, say which parts in the pull
request.

Anki's own contributors are listed in `CONTRIBUTORS` and are not repeated
here.
