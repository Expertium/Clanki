# Clanki

An Anki fork that aims to simplify the UI while adding more advanced spaced repetition algorithms. It is not ready to be released yet.

## Licensing

Clanki is a fork of Anki and is not official Anki. It is distributed under the
same AGPL-3 license as Anki, with Anki's own notices kept unchanged
(`LICENSE`). An author of Clanki code may also offer their own contribution to
Anki under the BSD-3 license, so that Anki can reuse it. That offer covers
only the work of the authors who made it, and `CONTRIBUTORS-CLANKI.md` lists
both the authors who have granted it and the code that stays outside it.
