- Preferences has a new UI split tab: you choose, item by item, what Simple
  mode shows. It lists the main window's Tools menu, deck list buttons,
  deck menu and deck-screen buttons, the Learn count, the reviewer's More
  menu, and the Browser's menus, search-bar switch, sidebar sections and
  columns, each with a "Show in Simple mode" checkbox, a search field and a
  "Reset to defaults" button. The defaults are the split Clanki had before,
  so nothing changes until you edit it. Advanced mode still shows
  everything. The choices are stored in the collection and sync with it,
  and open windows update at once.
- A Tools menu item that Simple mode hides keeps its keyboard shortcut (for
  example F for Create Filtered Deck), like the Browser's hidden items
  already did.
- On start-up in Advanced mode, the Tools menu now shows its Advanced items
  and View > Advanced UI is ticked at once, instead of only after the mode
  was switched.
